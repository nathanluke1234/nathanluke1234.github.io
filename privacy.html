LOIS privacy policy

LOIS is a private wall display used by one household. Its only user is its owner.

What it accesses

  • Google Calendar, read only, to show upcoming events.
  • Gmail, read only, to show a one-line summary of recent messages that need a reply.

What it does with it

  • Data is fetched by a device in the owner's home and shown on that device's screen.
  • Nothing is sold, shared, or used for advertising.
  • Email text is sent to Anthropic's Claude API only to produce the one-line summary, and is not stored by LOIS.
  • LOIS never sends, deletes or changes email or calendar events.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

LOIS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
